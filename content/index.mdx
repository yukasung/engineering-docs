## ภาพรวม (Overview)

Engineering Hub เป็นฐานความรู้กลางของทีม แบ่งเนื้อหาตามงานเพื่อให้ค้นหาได้ง่ายและลดเอกสารซ้ำ

- **Projects** รวบรวม Requirement, Architecture, API, ข้อมูล และข้อจำกัดของแต่ละโครงการ
- **Development Workflow** อธิบาย Git, Pull Request, Code Review, SDD และ Environment
- **Technology Guides** รวบรวมวิธีใช้ Framework, Database, Container และ Platform
- **Engineering Standards** กำหนดข้อตกลงด้าน Code Quality, Secure Coding และ Code Review ที่ใช้ร่วมกัน
- **Standards & Compliance** เป็นจุดเริ่มต้นสำหรับ ISO, PDPA และหลักฐาน Compliance

Developer, QA, System Analyst, DevOps, Architect และสมาชิกใหม่จึงค้นหาข้อมูลจากจุดเดียว ลดคำถามซ้ำ และอ้างอิงข้อมูลชุดเดียวกันได้

## วิธีใช้งาน

1. ค้นหาหัวข้อก่อนเริ่มงานหรือก่อนถามทีม
2. เปิด **Projects** เมื่อต้องเข้าใจระบบ และเปิด **Development Workflow** เมื่อต้องเริ่มหรือส่งต่องาน
3. เปิด **Technology Guides** เมื่อต้องใช้เครื่องมือ
4. เปิด **Engineering Standards** เมื่อต้องเขียนหรือ Review Code และกำหนด Quality Gate
5. เปิด **Standards & Compliance** เมื่อต้องออกแบบ Control หรือตรวจ Scope, Owner และ Evidence ของข้อกำหนด
6. ถ้าข้อมูลไม่ตรงกับระบบจริง ให้แจ้งทีมและแก้เอกสารพร้อมกับงานที่เปลี่ยน

## สิ่งที่ควรจำ

- เลือกหมวดตามงาน ไม่คัดลอกเนื้อหาเป็นหลายแหล่ง
- Workflow บอกวิธีทำงาน Technology Guides บอกวิธีใช้เครื่องมือ
- Security และ Compliance requirements ต้องยืนยัน Scope และ Owner ของระบบจริง
- ทุกคนช่วยกันทำให้เอกสารตรงกับงานจริง
