# React Component Library

## ภาพรวม (Overview)

React Component Library คือชุด Components กลางสำหรับ React และ TypeScript ช่วยให้ทีมใช้รูปแบบหน้าจอและพฤติกรรมที่สอดคล้องกัน โดยไม่ต้องสร้าง Component เดิมซ้ำในแต่ละโปรเจกต์

## ใช้เมื่อไร?

เปิดเอกสารนี้ก่อนสร้าง Input หรือ Form Component ใหม่ เพื่อตรวจว่ามี Component ที่ตอบโจทย์อยู่แล้วหรือไม่ รวมถึงดู Props ตัวอย่างการใช้งาน และข้อจำกัดของแต่ละ Component

## เอกสาร Component Library

- [เปิด React Component Library](https://react-component-library-docs.vercel.app/) — ดูรายการ Components, API และตัวอย่างการใช้งานล่าสุด

Engineering Hub เก็บเฉพาะลิงก์กลาง ส่วนรายละเอียดของ Component ให้ดูจากเอกสารต้นทาง เพื่อป้องกันข้อมูลซ้ำและเอกสารคนละเวอร์ชัน

## ข้อควรระวัง

- ตรวจสอบ Version ของ Library ที่โปรเจกต์ใช้อยู่ก่อนคัดลอกตัวอย่าง
- ทดสอบ Accessibility, Validation และพฤติกรรมบนหน้าจอจริงของโปรเจกต์
- หากต้องเพิ่มหรือแก้ Component ควรแก้ที่ Repository ของ Component Library แล้วให้โปรเจกต์อัปเดต Version ตามขั้นตอนของทีม
