# Technology Guides

## ภาพรวม (Overview)

ใช้หมวดนี้สำหรับแนวคิดและวิธีใช้เครื่องมือที่ไม่ผูกกับ Business domain ส่วนค่าจริงของแต่ละระบบ เช่น Hosts, Resource limits และ Deployment steps อยู่ใน Project Documentation และต้องไม่บันทึก Secrets

## วิธีเลือกใช้

เริ่มจากงานที่จะทำและคู่มือของเครื่องมือที่ใช้ อ่าน Applicable Technology Versions และแยกตัวอย่างออกจาก Verified implementation หาก Version ยังไม่ระบุ ให้ตรวจคู่มือของรุ่นที่โครงการ Pin ก่อนนำไปใช้
