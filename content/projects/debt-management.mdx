# Debt Management System — TCG

## ภาพรวม (Overview)

ระบบบริหารจัดการหนี้ของ Thai Credit Guarantee Corporation (TCG) มุ่งเน้นความถูกต้องของข้อมูล ความน่าเชื่อถือของระบบ และการดูแลรักษาในระยะยาว

## ขอบเขตงาน

- วิเคราะห์และแก้ปัญหาความถูกต้องกับความสอดคล้องของข้อมูล
- ตรวจสอบปัญหาระบบและฐานข้อมูลเพื่อหา Root cause
- ทำงานร่วมกับทีมพัฒนาเพื่อแก้ Technical issues และปรับปรุงขั้นตอนทำงาน
- สนับสนุนการปรับระบบเพื่อเพิ่ม Data quality, Reliability และ Maintainability
