# MatterSolv — Law Firm ERP & Management SaaS

## ภาพรวม (Overview)

MatterSolv เป็นแพลตฟอร์ม ERP และ SaaS แบบ Multi-tenant สำหรับสำนักงานกฎหมาย ออกแบบเพื่อรวมงานด้านกฎหมายและการบริหารธุรกิจไว้ในระบบเดียว

รายละเอียดเชิงลึกและข้อมูลล่าสุดให้ใช้ MatterSolv Documentation เป็นแหล่งอ้างอิงหลัก

## เอกสารโปรเจกต์

- [เปิด MatterSolv Documentation](https://mattersolv-docs.vercel.app/docs)

## ขอบเขตระบบ

- Client, Matter, Calendar, Task, Time และ Document management
- Quotation, Contract, Billing, Payment, Accounting และ Finance
- Employee, Leave, Reporting, Analytics และ System administration
- React และ TypeScript สำหรับ Frontend
- Python, Django และ Django REST Framework สำหรับ Backend กับ REST APIs
- PostgreSQL และ Multi-tenant architecture
- Authentication, Authorization, RBAC, Tenant isolation และ Data protection
- AI-assisted case analysis workflows

## ข้อมูลสำหรับทีมโครงการ

- Versions, Current implementation status และ Deployment environments
- Owner, Repository และสิทธิ์เข้าถึง
- Module scope, Security controls และ Operations ที่ใช้งานจริง
