# Sales & KPI Reporting System — Devineware

## ภาพรวม (Overview)

ระบบรายงานยอดขายและ KPI สำหรับ Devineware ในสหรัฐอเมริกา พัฒนาต่อยอดจาก Legacy Windows application ไปเป็น Web platform

## ขอบเขตระบบ

- ย้ายระบบเดิมบน Windows ไปเป็น Web-based platform
- ออกแบบ Database schema ใหม่
- เขียน SQL procedures สำหรับ KPI reporting ใหม่
- พัฒนา Module วิเคราะห์ยอดขายหลายเมือง

## ข้อมูลที่ยังไม่มี

- Technology stack และ Versions ที่ใช้จริง
- KPI definitions, Data sources และ Calculation rules
- Security, Environments, Deployment และ Operations
- Owner, Repository และ Canonical documentation URL
